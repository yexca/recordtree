> [!NOTE]
> Docker images support `linux/amd64` only. The Compose service listens on the
> host's loopback interface; remote access requires an authenticated proxy or
> an SSH tunnel.

RecordTree v0.1.0 imports the Record Tree Excel export into a local SQLite
library and provides a CLI and Docker WebUI for searching records, choosing
MEGA links, and following downloads through MEGAcmd.

<details>
<summary><strong>Import and library synchronization</strong></summary>

- Import Record Tree exports as `.xlsx` or `.xlsm` workbooks.
- Synchronize the library to each workbook while preserving download status
  with each MEGA URL. Records omitted from a workbook are hidden and return
  when a later import includes them.
- Keep records whose files have no MEGA links yet available in search.

</details>

<details>
<summary><strong>Search and library browsing</strong></summary>

- Search by actor, title, source, date, file type, and download status.
- Browse actor favorites and platforms, and inspect record metadata, file
  names, link sizes, and download status.
- Keep record filters, sorting, pagination, and the open detail drawer in the
  URL so navigation and reloads return to the same view.

</details>

<details>
<summary><strong>Downloads and recovery</strong></summary>

- Select individual links and review a download plan with disk-space checks
  before starting MEGAcmd. File-type filters and the `.par2` preference help
  choose links.
- Queue downloads for an actor's newest records with undownloaded links.
- Resume unfinished WebUI downloads while keeping completed links. Download
  state is saved between transfers, and full MEGAcmd output is kept on disk.

</details>

<details>
<summary><strong>WebUI and maintenance</strong></summary>

- Follow background imports and downloads with progress and live MEGAcmd
  output, and inspect past imports, row errors, and download logs.
- Configure download directories, folder templates, disk-space margins, and
  the default `.par2` preference.
- Manage the MEGAcmd account, create database backups, and run integrity
  checks and maintenance tools.

</details>

<details>
<summary><strong>Installation and deployment</strong></summary>

The Docker image includes MEGAcmd and is available from either registry:

```text
yexca/recordtree:0.1.0
ghcr.io/yexca/recordtree:0.1.0
```

- Keep configuration, the database, logs, MEGAcmd state, downloads, and uploaded
  workbooks in mounted host directories. Follow the
  [Docker guide](https://github.com/yexca/recordtree/blob/v0.1.0/docs/user-guide/docker.md)
  for setup, login, and persistent storage.
- Install the Windows CLI with `run-install.bat` and follow the
  [CLI guide](https://github.com/yexca/recordtree/blob/v0.1.0/docs/user-guide/cli.md).
  CLI downloads require a MEGAcmd installation and login.
- RecordTree is licensed under AGPL-3.0-only.

</details>
